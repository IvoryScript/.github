# IvoryScript

IvoryScript is a declarative programming language for dynamic programming and data storage.

It combines static typing with first-class expressions, names, and types and controlled reduction
— and also maintains the context associated with values.
All general data types support copying and binary serialisation.

## IvoryScript

The main [IvoryScript repository](https://github.com/IvoryScript/IvoryScript) contains the source code, build instructions, examples, and regression tests.
